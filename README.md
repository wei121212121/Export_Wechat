# 微信聊天记录导出工具

这是一个面向中文 Windows 用户的微信聊天记录导出项目。项目的核心目标，是把用户本人有权访问的微信聊天数据整理并导出为 TXT、Markdown 等便于阅读、检索和长期保存的格式。

语音转文字模型只是可选附加组件，不是本项目的核心。没有语音模型时，聊天记录导出主流程仍然可以独立使用；只有需要把语音消息转换为文字时，才需要额外准备模型。

## 项目定位

- 核心功能：导出、整理和阅读微信聊天记录
- 目标用户：需要处理中文微信聊天数据的 Windows 用户
- 输出方向：TXT、Markdown 等本地文件
- 运行方向：优先离线、本地处理
- 隐私原则：聊天记录和账号数据不进入公开 Git 仓库

本仓库目前更接近“内测版发布与构建交接仓库”，不是完整的原始 Rust/Tauri 源码仓库。现有构建流程基于已有 Windows 程序进行补丁处理；如果要进行长期维护，仍需要补齐原始源码和正式构建链。

## 使用流程

1. 准备你本人有权处理的微信数据，并先备份重要数据。
2. 下载对应的 Windows 内测程序发布包。
3. 运行中文启动脚本。
4. 在程序中选择导出范围和输出格式。
5. 到本地“导出结果”目录查看 TXT 或 Markdown 文件。
6. 如需语音转文字，再单独安装语音模型并启用相关功能。

不要把真实聊天导出文件、微信数据库、账号缓存、密码、授权令牌或调试文件提交到 GitHub。

## 可选语音转文字组件

语音模型只服务于“语音消息转文字”这一附加功能：

- 模型目录：`models/sensevoice/`
- 模型文件：`model.int8.onnx`、`tokens.txt`
- 模型用途：本地语音转文字
- 模型不等于聊天记录，也不包含用户聊天内容

模型压缩包使用 Git LFS 存储。安装 Git LFS 后执行：

```bash
git lfs pull
```

下载并解压模型后，把 `models` 文件夹放到程序目录旁边，再使用启动脚本。

## 隐私和安全边界

本项目处理的内容可能高度私密。使用时请注意：

- 只导出你本人有权访问和处理的聊天记录；
- 先用副本测试，不要直接在唯一数据上实验；
- 不要公开上传聊天记录、联系人信息、头像、手机号、账号数据或数据库文件；
- 不要把本机调试日志、缓存、临时导出目录提交到 GitHub；
- 程序未签名时，Windows 可能显示安全提示；
- “离线”只描述当前设计方向，不代表所有外部构建或下载环节天然安全。
