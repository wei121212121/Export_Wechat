# 微信聊天记录导出工具

这是一个 Windows 微信聊天记录导出工具，主要用于把聊天记录导出为 TXT、Markdown 等文件。

## 下载哪个文件？

推荐下载：`微信聊天记录导出工具-完整便携版.zip`

解压后直接运行里面的程序即可。单独的 `微信聊天记录导出工具.exe` 是程序本体，但完整便携版包含运行所需的附属文件，优先使用完整便携版。

## 语音转文字（可选）

`微信聊天记录导出工具-语音转文字模型.zip` 只是附加功能，用来把聊天中的语音消息转换成文字。

不需要语音转文字时，不用下载模型。需要时，把模型压缩包解压出的 `models` 文件夹放到程序目录旁边即可。

## 使用步骤

1. 下载完整便携版；
2. 解压；
3. 运行程序；
4. 选择聊天记录和导出格式；
5. 在本地查看导出的 TXT 或 Markdown 文件。

请只导出你本人有权处理的微信数据。不要上传聊天记录、微信数据库、账号信息、密码或导出结果。

当前版本属于内测版，原始完整源码尚未公开。`微信聊天记录导出工具.exe` 和便携包使用 Git LFS 保存，下载大文件前请安装 Git LFS 并运行 `git lfs pull`。
