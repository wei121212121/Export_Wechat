# 微信聊天记录导出工具｜Windows 中文离线内测版

这是一个面向中文 Windows 用户的微信聊天记录导出工具。项目核心用途是把用户本人有权访问的微信聊天数据整理并导出为 TXT、Markdown 等本地文件。

语音转文字模型只是可选附加组件，不是项目主体。

## 程序本体和完整便携包

- `ExportWeChat-无限制内测版.exe`：程序本体；
- `ExportWeChat-中文安全便携包-v1.zip`：已经排除聊天导出结果的安全便携包，包含程序运行所需的附属文件、资源和启动脚本。

推荐下载并解压 `ExportWeChat-中文安全便携包-v1.zip`，然后运行其中的 `启动内测版.cmd`。不要把程序本体和聊天导出结果混在一起公开分享。

## 使用方式

1. 下载 `ExportWeChat-中文安全便携包-v1.zip`；
2. 解压到本地目录；
3. 使用 `启动内测版.cmd` 启动；
4. 在程序中选择聊天记录范围和 TXT、Markdown 等输出格式；
5. 在程序目录下的 `导出结果` 文件夹查看结果。

完整便携包中还包含 `ew.exe`、`exportwechat-client.exe`、`uninstall.exe`、`exporter`、`format-examples` 和必要的启动/卸载脚本。原始完整包中发现的聊天导出目录已排除，没有上传。

## 可选语音转文字模型

语音模型只用于把聊天中的语音消息转换为文字。下载 `ExportWeChat-中文语音模型-v1.zip` 后解压，将其中的 `models` 文件夹放到程序目录旁边。只导出普通文字、图片或链接时，可以不安装模型。

## 隐私和安全

请只处理你本人有权访问的数据，并在测试前备份重要微信数据。不要上传聊天记录、数据库、联系人信息、账号缓存、密码、授权令牌、调试日志或导出结果。程序未签名时，Windows 可能显示安全提示。
